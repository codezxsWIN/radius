# Basic AI Agent Discussion Questions

Use these questions to guide a beginner-friendly discussion about AI agents. They move from core ideas to practical design, safety, evaluation, and real-world use.

## Foundations

1. What is an AI agent in simple terms?
2. How is an AI agent different from a regular chatbot?
3. What does it mean for an agent to have a goal?
4. What kinds of tasks are agents good at handling?
5. What kinds of tasks are agents not good at handling yet?
6. Why do agents often need access to tools?
7. What is the difference between an agent and an automation script?
8. What does "autonomy" mean when talking about AI agents?
9. Why is step-by-step reasoning useful for agents?
10. What does it mean for an agent to make a plan?

## Inputs, Outputs, and Context

11. What information does an AI agent need before it can start a task?
12. Why is context important for an agent?
13. What can happen if an agent has missing or wrong context?
14. How should a user give instructions to an agent?
15. What makes a prompt clear for an agent?
16. Why should agents ask follow-up questions sometimes?
17. When should an agent make a reasonable assumption instead of asking the user?
18. What is the difference between a user instruction and background information?
19. Why should an agent explain important decisions to the user?
20. How can an agent summarize progress during a long task?

## Tools and Actions

21. What is a tool call in an AI agent system?
22. Why might an agent need to search files in a project?
23. Why might an agent need to browse the internet?
24. What are examples of tools an agent might use?
25. How can tool access make an agent more useful?
26. What risks come from giving an agent access to tools?
27. Why should agents verify results after using tools?
28. What does it mean for an agent to run code?
29. Why should agents avoid changing unrelated files?
30. How can an agent decide which tool to use first?

## Memory and State

31. What is memory in an AI agent?
32. How is short-term context different from long-term memory?
33. What should an agent remember about a user?
34. What should an agent avoid remembering?
35. Why is it useful for an agent to know the current project state?
36. How can an agent recover after losing some context?
37. What does it mean for an agent to be stateful?
38. How can saved decisions help future agent work?
39. Why should agents be careful with private information?
40. How can users control what an agent remembers?

## Safety, Reliability, and Evaluation

41. What does it mean for an agent to be reliable?
42. Why do agents sometimes make mistakes?
43. What is hallucination in an AI system?
44. How can an agent reduce hallucinations?
45. Why are tests important when an agent changes code?
46. What should an agent do when it is unsure?
47. Why is human review still important for agent work?
48. What makes an agent's answer trustworthy?
49. How can we measure whether an agent completed a task successfully?
50. What is one real-world task where an AI agent could save time?
