## Stubbed, Deferred and Known Limits

- No known failing tests remain. Fixed regressions include full-result input-order determinism, missing type-filter options, mobile grid overflow, actor-restricted deny leakage and unsafe recursive template replacement. Tests do not establish absence of undiscovered defects.
- Explicit what-if accepts allow or deny additions/removals; removing a deny can increase reach and that positive delta is reported. The automatic recommendation search still only considers allow-binding removals, so it never recommends disabling a deny as a risk reduction.
- No production live tenant scan is delivered. The library transport is implemented and fake-response tested but never executed against Azure. It returns a non-synthetic in-memory bundle that this prototype refuses to score or persist.
- App/directory role capabilities, PIM approval applicability and CA credential-stage applicability use explicit reviewed synthetic sidecars. Arbitrary role semantics, delegated sessions, CA OR/exclusions/claims and token scope/refresh/on-behalf-of behavior are deferred, not inferred.
- The public Graph v1.0 service-principal group membership omission, hidden membership authorization, management-group scope, external tenants and directory administrative-unit scope require dedicated conformance before a live release.
- Finite operation catalogs cover storage-account metadata/write and vault metadata/secret-read outcomes. General provider action catalogs, scope-specific resource policies and compound authorization requirements are not complete. Unknown resource types are coverage gaps.
- HMAC uses a private external 32-byte OS-random key. It supports local integrity, not public attestation. The key is not in the zip, source, HTML or fixture set. Verifying an old result on another machine needs its original key through a trusted separate process; regenerating the synthetic result creates a new local key if needed.
- Synthetic results are plaintext by explicit session scope. Authenticated encrypted persistence, secure key custody and private disclosure handling are mandatory before real inputs.
- Exhaustive p95 recommendations run for small graphs only and evaluate every eligible candidate. Above 200 credentials or 5000 edges, recommendation search is explicitly deferred; no sampled optimum is claimed. A single-binding recommendation ignores business utility and multi-change dependencies.
- Shared synthetic roles make all 80 demo credentials exceed 25% and yield low Gini. This is a constructed scenario, not evidence for the paper's population hypothesis.
- No hosted web app was published: the required artifact is a complete self-contained static dashboard and needs no server. No cloud deployment or publication was attempted.
- OneDrive checkpoint writes and zip hashes are verified locally. Cloud synchronization status is not independently verified.
