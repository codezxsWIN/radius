# Project Scope: Standard, Conformance, Open Data

This direction supersedes the earlier product/prototype roadmap. Blast Radius is an open metric standard, a public conformance suite with reference code, and a planned open aggregate dataset. It is not a CIEM product, and no real-world dataset or exclusive novelty claim is established by the synthetic work in this repository.

Code is Apache-2.0; specification/schema are CC BY 4.0; published aggregate data will be CC0. There are no paid tiers, enterprise edition, certification charges, SSO, multi-tenant consoles, compliance packs, SIEM or ticketing integrations. Neutral governance must exist before the first public real-data aggregate.

## v0.1 Scope Audit

- The single existing demo page is retained as an illustrative artifact and is not expanded or regenerated over user changes.
- What-if and path explanations remain evaluation instruments; automated recommendation ranking is demoted to the existing demonstration, not a normative standard requirement or an enterprise remediation feature.
- SARIF remains a legacy local serialization adapter, not an integration roadmap. No SIEM/ticketing connector exists to delete.
- Entra/AWS offline adapters remain experimental normalization artifacts; the gated live transport remains unexecuted and is not a managed service roadmap.
- No SSO, multi-tenant management, billing or compliance-pack code exists in the inspected v0.1 surface. Such features are permanently outside scope.
- The benchmark architecture is downloadable aggregates on a static site plus, eventually, a minimal reviewed intake function. Free tiers/academic credits are a budget constraint, not a guarantee of unlimited cost-free capacity.
