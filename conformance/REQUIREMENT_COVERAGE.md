# Requirement Coverage and Claim Boundaries

Passing a mapped fixture means the tested behavior passed, not that every sentence in a requirement was formally proven. The machine reports enumerate fixture IDs and requirement mappings; this ledger distinguishes executable evidence from remaining review obligations. Core arithmetic conformance is separate from input provenance, provider completeness, community governance and privacy approval.
