# Prospective Synthetic Run Details

Written before the new500-tenant population is generated or inspected. This implements, but does not replace or retrospectively alter, PREREGISTRATION.md. The execution receipt binds both documents before the first graph is generated. This is a local protocol record, not independently attested registration.

- Master seed20260909;500 paired tenant configurations; deterministic per-tenant seed `master + index*104729`; regime changes do not change the identity/resource population.
- Uniform discrete principal count20..80 inclusive, resource count10..30 inclusive. Uniform choice of the four preregistered NHI shares. Realized NHI count is the ceiling of count*share, so the0.5 grid point does not accidentally become a minority through downward rounding.
- Non-human subtypes cycle through service_principal, managed_identity, workload_identity and ai_agent, then all principal labels are shuffled before grants. One metadata credential and one binding per principal; no groups, deny policies, session gates or escalation in this experiment. This intentionally narrow topology cannot represent real enterprise complexity.
- Every resource has read/write/administer, with fixed action weights1/3/5. Resource sensitivity is a uniform choice from{0.2,0.5,0.8,1.0}. These are investigator-assigned sensitivity factors, not measured classifications.
- Grant degree drawn from1..8 with probability proportional to1/degree^2. Sample unique resource-action pairs without replacement. Null degree independent of identity type; positive control multiplies NHI degree by8; reversed control multiplies human degree by8, capped at the finite universe size. A separate grant-selection PRNG keeps the base degree draws identical across regimes.
- Primary result is the unchanged preregistered joint event and Wilson criterion, including its NHI-minority population ceiling. Report human union, NHI union, their overlap, total union, and per-principal median/p95 as secondary quantities. Merely observing extensive NHI reach while humans have equally extensive reach is not evidence of disproportionate NHI privilege.
- Privacy study uses only the null regime's500 summaries. Compare exact integer feature vectors, counts rounded down to multiples of10, and the21-cell proposed release projection. Feature scaling for nearest-neighbor distances uses observed per-column maxima in this synthetic diagnostic only; it is not used to select a real release.
- Draft aggregation: fixed21-cell histogram, target support k10, rational noise q1/2 (epsilon ln2), additive/removal adjacency for one deduplicated tenant. Compare q3/4 andq1/4 as prespecified sensitivity experiments,200 independent seeded trials each. Utility reports count MAE across all21 cells with null treated as0, released-support fraction and maximum absolute error; it does not hide suppression loss.
- Public noise seeds are only for reproducible synthetic tests. They are NOT acceptable randomness for real private releases. The default library sampler uses system randomness; real intake/release remain disabled pending neutral custody, independent review and durable deduplication/budget enforcement.

No parameter is a sourced cloud-population estimate. The missing distribution source is a remaining requirement, not something this synthetic study can manufacture.
